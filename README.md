# C++ Learning Workspace

This repository is a personal C++ learning workspace.

It contains multiple branches organized by topic:

- `DXX` branches: 42 school video tutorials
- `CPPXX` branches: C++ modules

## Purpose

The goal of this repo is to keep my C++ practice, exercises, and tutorial work in one place while separating each
learning track into its own branch family.

## Branch naming

| Branch prefix | Meaning                           |
|---------------|-----------------------------------|
| `DXX`         | 42 school video tutorial branches |
| `CPPXX`       | C++ module branches               |
